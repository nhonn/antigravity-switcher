# Antigravity Menu Bar

A native macOS menu bar application for Antigravity Manager.

## Requirements

- macOS 13.0+
- Swift 5.9+

## Project Structure

- `Sources/`: Swift source code
- `assets/`: Application assets (icons)
- `build.sh`: Build script to create the .app bundle

## Building

Run the build script:

```bash
./build.sh
```

The application will be built in `build/AntigravityMenuBar.app`.
